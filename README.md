# FoodSwift - High-Fidelity UI Redesign

## Project Overview
FoodSwift is a high-fidelity UI/UX redesign project for a food delivery website inspired by modern platforms like Swiggy and Zomato. The project focuses on improving usability, visual hierarchy, responsive layouts, and overall user experience for both desktop and mobile users.

This redesign was created as part of an internship task to practice UI/UX principles, responsive web design, and modern interface creation using Figma.

---

## Objective
- Improve website usability and navigation
- Create a modern and visually appealing interface
- Design responsive layouts for desktop and mobile
- Practice visual hierarchy and layout organization
- Understand responsive UI/UX design principles

---

## Heuristic Evaluation

### Problems Identified in Existing Website
- Cluttered interface
- Inconsistent spacing
- Weak visual hierarchy
- Small clickable elements
- Difficult navigation flow
- Poor mobile responsiveness

### Improvements Made
- Cleaner layout design
- Better spacing and alignment
- Improved typography hierarchy
- Modern responsive cards
- Easy-to-use navigation
- Mobile-friendly responsive layouts
